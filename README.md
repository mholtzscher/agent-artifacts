# Agent Artifacts

Agent Artifacts is a public artifact feed for documents generated by coding agents.

## MVP routes

Public reads:

- `GET /` — recent artifact feed
- `GET /a/:slug` — rendered artifact page
- `GET /source/:slug` — immutable source
- `GET /api/artifacts` — recent artifact JSON

Protected writes:

- `POST /api/artifacts` — publish a Markdown or HTML artifact using `X-Write-Key`

## Configuration

Required:

```sh
AGENT_ARTIFACTS_WRITE_KEY=ap_some_secret
```

Optional:

```sh
PORT=3000
PUBLIC_BASE_URL=http://localhost:3000
DATABASE_URL=file:./data/agent-artifacts.db
STORAGE_DIR=./data/files
```

## Run locally

With direnv:

```sh
echo 'AGENT_ARTIFACTS_WRITE_KEY=ap_test' > .env
direnv allow
bun install
bun run start
```

Without direnv:

```sh
bun install
AGENT_ARTIFACTS_WRITE_KEY=ap_test bun run start
```

Publish an artifact:

```sh
curl -X POST http://localhost:3000/api/artifacts \
  -H "X-Write-Key: ap_test" \
  -F "file=@PLAN.md" \
  -F "title=Implementation Plan"
```

## Docker

```sh
docker build -t agent-artifacts .
docker run --rm -p 3000:3000 \
  -e AGENT_ARTIFACTS_WRITE_KEY=ap_test \
  -e PUBLIC_BASE_URL=http://localhost:3000 \
  -v agent-artifacts-data:/data \
  agent-artifacts
```

## Development

```sh
bun run check
bun run lint
bun run test -- --run
```

The implementation uses Effect Platform for HTTP, Effect SQL SQLite for metadata, Effect Schema/Brand for core domain types, and filesystem storage for immutable artifact source.
